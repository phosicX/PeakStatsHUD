# Upstream references

These folders contain the original mod packages PeakStatsHUD is based on. They are kept for
attribution, comparison and licence compliance; they are not part of the build.

- `LengSword-PeakStatsEx-1.5.4` — PeakStatsEx by LengSword (MIT).
  Source: https://codeberg.org/yls-peak-mods/PeakStatsEx
- `TactiKot-StaminaStatsTactikot-1.3.7` — StaminaStatsTactikot by TactiKot (MIT), based on
  StaminaStats by pixx.

PeakStatsHUD's source is a modified copy of the PeakStatsEx source with the HUD layout adapted
to the StaminaStatsTactikot style.
